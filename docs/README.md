## Fundamental Principle

> **HAAR → EVIDENCE**\
> **HUMAN → DECISION**

HAAR does not primarily ask whether a person wrote the text. It assesses
whether the respondent can reconstruct, justify, challenge, transform,
and extend the scientific reasoning represented by the submitted work.
